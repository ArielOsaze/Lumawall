Kenapa LumaWall

Semua yang wallpaper engine seharusnya lakukan

Dibuat ulang dari nol untuk performa. Setiap keputusan teknis punya alasan yang bisa kamu rasakan langsung di desktop.

GPU, bukan CPU

Video didecode di chip grafis (NVDEC / DXVA) dan dikomposit lewat DWM. Hasil ukur: pemakaian CPU 0% saat tiga wallpaper 1080p berjalan bersamaan.

Pause per-monitor

Game fullscreen di monitor 2 hanya menghentikan wallpaper monitor 2. Monitor 1 dan 3 tetap beranimasi. Tidak ada lagi wallpaper yang ikut mati karena aplikasi di layar lain.

Respons 4 milidetik

Pause dan resume dipicu oleh event sistem Windows, bukan polling. Terukur 4 ms saat fullscreen dibuka dan 1 ms saat ditutup — tanpa perlu klik apa pun.

Satu wallpaper, beda tiap layar

Pasang video berbeda di setiap monitor, atau simpan seluruh susunan sebagai profil dan pulihkan dengan satu klik. Layout monitor berubah? LumaWall menyesuaikan sendiri.

Katalog 5.000 wallpaper

Cari karakter atau suasana, lihat preview, lalu unduh. Setiap unduhan menyertakan file .license.txt berisi kreator, lisensi, dan tautan sumbernya.

Tidak menyentuh file kamu

Wallpaper ditempatkan di lapisan desktop Windows (WorkerW), jadi ikon desktop dan aplikasi biasa tetap di atasnya. Tidak ada overlay yang mencuri klik.

Pertanyaan

Yang sering ditanya

Apakah LumaWall memberatkan komputer?

Tidak. Video didecode di GPU, bukan CPU. Pada tiga wallpaper 1080p yang berjalan bersamaan, proses utama LumaWall memakai CPU di bawah 1%. Aplikasi juga berhenti melakukan decode saat layar terkunci, mati, atau saat memakai baterai.

Bagaimana kalau saya main game fullscreen?

Wallpaper di monitor yang tertutup game langsung berhenti, dalam sekitar 4 milidetik, dan jalan lagi begitu game ditutup atau diminimize. Monitor lain tetap beranimasi — pause bekerja per layar, bukan untuk semua monitor sekaligus.

Apakah ikon desktop saya masih bisa diklik?

Bisa. LumaWall menempatkan wallpaper di lapisan desktop Windows (WorkerW), tepat di bawah ikon. Ia bukan jendela overlay, jadi tidak mencuri klik, tidak muncul di Alt+Tab, dan tidak menghalangi apa pun.

Bisa pakai video saya sendiri?

Bisa. Klik Tambah dan pilih file video atau gambar milikmu (mp4, m4v, wmv, avi, mov, webm, jpg, png, bmp). LumaWall juga menyimpan file .license.txt untuk setiap unduhan dari katalog.

Bagaimana kalau Explorer saya restart atau crash?

LumaWall memeriksa kesehatannya setiap dua detik. Kalau jendela desktop hilang, wallpaper dibangun ulang dan dipasang kembali secara otomatis dalam waktu kurang dari empat detik — tanpa perlu menjalankan ulang aplikasi.

Apakah ada iklan atau pelacakan?

Tidak ada iklan, tidak ada akun, dan tidak ada telemetri. Satu-satunya koneksi internet adalah saat kamu sendiri mengunduh wallpaper dari katalog.

Bahasa apa saja yang didukung?

Antarmuka tersedia dalam Bahasa Indonesia, English, 简体中文, dan 日本語. Kamu bisa menggantinya kapan saja lewat pemilih bahasa di bar atas.

Desktop kamu layak terlihat hidup

Gratis, tanpa iklan, dan dirancang supaya kamu lupa kalau ini sedang berjalan.
