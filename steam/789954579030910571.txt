 4.1 GB of RAM usage is quite a lot (my current wallpaper is using 23 Megabytes for reference) but if this number makes sense in the context of your wallpaper, you can change the "Other application fullscreen" option to "Stop (free memory)" in the Wallpaper Engine settings. This will fully unload Wallpaper Engine while any app is fullscreened.

 Generally it looks fine which makes it kind of annoying to debug. Could you try disable the following two features and see if this makes the issue go away?

1. Turn off "Override lockscreen image" and "Override wallpaper image" in Wallpaper Engine General settings.
2. In the "Plugins" tab of the Wallpaper Engine settings, disable the iCUE integration.

Afterwards, restart Wallpaper Engine and see if the issue persists and let me know. If the issue is fixed, maybe re-enable them one by one so I can better understand which exact feature might be causing this so that we can look into a fix. Apologies for all the hassle.

 I am afraid I cannot reproduce the issue, what's almost very ironic is that we have pretty much the same hardware setup, same Windows version, same driver versions, I might as well have a copy of your computer here.

I am just going to list every possible odd thing that I can spot, you don't really have to test it but I am kind of out of ideas to be honest.

1. The iCUE plugin was still enabled in your log file, maybe you can just double-check that it is / was really turned off?
2. You are cloning your display (which should be fine) but maybe for testing purposes, you could stretch the wallpapers across both screens (for example, anything except cloning basically)
3. I see you have this "PCManager" tool from Microsoft up and running, I have never even heard of this can you disable it just in case it's messing with the system memory in a crazy unexpected way?
4. Maybe even try this as a first step: It could be that some files are simply corrupt in a crazy way, causing this odd memory leak. You could try a clean reinstallation, that means uninstall the app via Steam, then manually delete the wallpaper_engine folder (very important to manually delete it) and then reinstall it via Steam.

Again, sorry for the hassle but at this point I am somewhat sure that there must be some insanely specific issue going on with your computer, also because we have had no similar reports and because I cannot reproduce the problem on an almost identical machine.
