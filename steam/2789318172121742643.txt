 Pause when display is off 

 Hey, great software, but I have a question. Is it possible to stop (pause/etc) wallpaper, while display is turned off? Because instead of turning my PC off entirely (and I'm not using sleep/hibernate mode aswell) - I'm turning off only a monitor itself, using physical button on it. 

 The author of this topic has marked a post as the answer to their question.

 Click here to jump to that post. 

 Originally posted by Tim :

 If you check the "Performance" tab in the settings, the "Display asleep" option should be set to "Stop (free memory)" which essentially means Wallpaper Engine unloads active wallpapers completely. 

However, I don't know if turning off your screen manually will relay this to Windows (very likely it does not but maybe test it somehow). In the Windows power settings, you have the option to turn off the display after a certain amount of time, though. Maybe using this option with an adequate time would be a workaround for you (for example, turning off the display after 10 minutes of inactivity).

Alternatively, set a hotkey in Wallpaper Engine to "stop" the current wallpapers which you could quickly press when leaving your PC.

 If you check the "Performance" tab in the settings, the "Display asleep" option should be set to "Stop (free memory)" which essentially means Wallpaper Engine unloads active wallpapers completely. 

However, I don't know if turning off your screen manually will relay this to Windows (very likely it does not but maybe test it somehow). In the Windows power settings, you have the option to turn off the display after a certain amount of time, though. Maybe using this option with an adequate time would be a workaround for you (for example, turning off the display after 10 minutes of inactivity).

Alternatively, set a hotkey in Wallpaper Engine to "stop" the current wallpapers which you could quickly press when leaving your PC.
