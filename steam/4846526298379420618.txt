 "Pausing" will still occupy VRAM, "Stopping" will not use any VRAM.

You can find these options in the "Performance" tab of the settings and in the hotkey settings.

 As explained above, if you pause a wallpaper, the same amount of VRAM will still be used. If you "stop" a wallpaper, no VRAM will be used. Please take a look at the performance tab of the Wallpaper Engine settings. If you want wallpapers to stop using video-ram while in-game, set the "Other application fullscreen" option to "Stop (free memory)".
