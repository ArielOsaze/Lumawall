 Describe the solution you'd like

    In the Settings > Performance tab, we can already configure what Lively does in certain scenarios (applications fullscreen, applications focused, etc.). As of right now, we can either make it stop animating the wallpaper in a certain scenario or keep animating it. I suggest adding a "reduced" mode that simply lowers the frame rate to something like 45 FPS (although the maintainers can change that number later or make it its own separate setting).

    For example, when I have an app focused, I still want to have the animated wallpaper, but I don't need it at 60 FPS since I'm not paying full attention to it -- "reduced" mode could be the middle ground, providing both a nice, animated wallpaper and low battery usage (and less resource utilisation on lower-end devices).
