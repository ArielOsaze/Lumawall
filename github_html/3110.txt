 Issue body actions 

 Describe the bug

 When using the pause feature of wallaper with multiple monitors , there are certain issues. context : both pause on focus and pause on fullscreen is on.

 When pausing is set to per screen :

monitor 1 has a window maximised

monitor 2 has a window full screened

when i switch the focus from monitor 2 to monitor 1 and vice versa , the unfocused monitor's wallpaper starts playing even though there is a fullscreen window in that monitor.

 When pausing is set to all screens :

Expected behaviour . opening one application in one monitor causes wallpaper to pause on all monitors.

 The main issue is that the wallpaper running on the unfocused monitor with the full screen or maximised application , causes the life of the gpu to reduce and break quicker.

 Steps to reproduce

 Set a live wallpaper on both the screens. I encountered this bug with different wallpapers .

 open a window on each monitor either full screen or maximised.

 switch focus from one monitor to other and check the difference of gpu usgae using task manager or similar software

 Expected behavior

 I expect the wallpaper to stop playing on a monitor when an apllication is open regardless if the monitor is focused or not
