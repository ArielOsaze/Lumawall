 Summary

 This PR introduces performance optimizations focused on RAM usage and adds Vulkan-based GPU hardware acceleration.

 Changes

 RAM optimization : Reduced memory footprint significantly (down to ~40MB in testing) by adding Vulkan ANGLE optimizations

 Vulkan GPU acceleration : Added Vulkan backend support for hardware-accelerated rendering, offloading work from CPU to GPU

 Testing

 Tested locally on Windows 11 — confirmed RAM usage dropped to ~40MB with Vulkan acceleration enabled.

 Notes

 Parts of this implementation were developed with AI assistance; happy to walk through any section in more detail if needed. 🙂
