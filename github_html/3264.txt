 Describe the bug

 When the same wallpaper is duplicated across multiple monitors, Lively pauses the wallpaper on all monitors when a fullscreen/maximized window is detected on just one monitor.

 The wallpaper should only pause on the monitor where the fullscreen/maximized window is located. Currently, maximizing a window on one monitor also pauses the wallpaper on the other monitors.

 might be similar to #3110 but tbh im not sure if its the same.. the description there is not clear.

 Steps to reproduce

 Connect two or more monitors.

 Set the same video wallpaper to play on both monitors.

 Open a window on Monitor 1 and maximize it or make it fullscreen.

 Observe the wallpaper playback on both monitors.

 Repeat by maximizing a window on Monitor 2.

 Expected behavior

 The wallpaper pause behavior should be per monitor.

 If a fullscreen/maximized window is present on Monitor 1, the wallpaper should pause only on Monitor 1.

 The wallpaper on Monitor 2 should continue playing normally.

 Maximizing a window on Monitor 2 should not pause the wallpaper on Monitor 1.

 Each monitor should independently pause/resume its wallpaper based on the windows displayed on that specific monitor.
