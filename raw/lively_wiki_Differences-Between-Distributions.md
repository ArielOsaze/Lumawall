## Installer/Github release
Require installation of .NET runtime and other dependencies on host system (admin account is required during installation.)

Distributed and updated via github. 

Requires Windows 10 1903 or above.

**Download:** https://github.com/rocksdanister/lively/releases

## Windows Store
Does NOT Require installation dependencies on host system. 

Distributed and updated via Microsoft store with fast download speeds and incremental updater.

Requires Windows 10 1809 or above.

#### Limitations:
1. No application wallpaper (unity, godot..) support.
2. For the time being not possible to install additional wallpaper plugins.
3. App needs to run in the background for Screensaver(s) to work.

**Download:** https://apps.microsoft.com/store/detail/9NTM2QC6QWS7
