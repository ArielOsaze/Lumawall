## Setup

### System Requirement
The minimum hardware required to run Lively is as follows:
* OS: Windows 10 1903 or above (Installer) / Windows 10 1809 or above (Windows store)
* Processor: Intel i3 or equivalent
* Memory: 4096 MB RAM 
* Graphics: Intel HD Graphics 4600 or above  
* DirectX: Version 10 or above  
* Storage: 1GB available space
 
Check the [Performance](https://github.com/rocksdanister/lively/wiki/Performance) page for additional information.

For installer version of Lively additional dependencies are required to be installed, the setup will handles this so follow the instructions during installation.

For Microsoft store version of Lively no additional setup is required, to learn the difference between distributions [click here.](https://github.com/rocksdanister/lively/wiki/Differences-Between-Distributions)

### Storage

Wallpapers and settings are stored for each user based on the distribution:

#### Installer

`%LocalAppData%\Lively Wallpaper`

`%LocalAppData%\Temp\Lively Wallpaper`

#### Microsoft Store

`%LocalAppData%\Packages\12030rocksdanister.LivelyWallpaper_97hta09mmv6hy\LocalCache\Local`

For installer version when uninstalling user will be prompted whether to delete this folder.

For Microsoft Store version the data will be automatically removed without any prompt.

### Windows settings (optional)
In some older versions of Windows for live wallpapers to work user will need to modify Windows settings as follows:
1. Press the Win + R keys to open Run, type SystemPropertiesPerformance.exe into Run, click on "OK" to open Performance Options.
2. Enable/Check "Animate controls and elements inside windows" (If already checked, then uncheck and check.) & Apply.
3. Click "Apply" then press "OK" to close the window.

### High Contrast Mode
High contrast mode in windows disables certain visual features, all features of Lively may not function properly in this mode.
