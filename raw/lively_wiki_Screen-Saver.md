Lively supports running wallpaper as [Windows Screensaver.](https://en.wikipedia.org/wiki/Screensaver)

Works with all wallpaper types (videos, picture and gifs, webpages..)

Think of Lively as a powerful screen saver manager with modern features like multiple monitor support.

#### Note
In the Microsoft Store version, the Lively app must run in the background for screensavers to work. However, in the installer version, screensavers can run independently without the app being open.

## Setup instructions

Lively screensavers can be setup in several ways, follow any one of the following methods.

#### 1. Built-in Screensaver manager
For Microsoft Store navigate to Settings -> Screensaver and follow the instructions.

<img width="450" src="https://github.com/user-attachments/assets/cf46ed06-a4f2-4584-b16e-9874ff84a8e0" />


#### 2. Windows Screensaver file
1. Download the screensaver file [lively_utility_screensaver.zip](https://github.com/rocksdanister/lively/releases/download/v2.2.0.0/lively_utility_screensaver.zip)
2. Extract the zip, copy the .scr file to `C:\Windows\Lively.scr`
3. Right-click the copied .scr file -> Install.
4. Select `Lively` screensaver in [Windows settings.](https://www.windowscentral.com/how-enable-screen-savers-windows-10)
5. Configure it - set the time out and enjoy!
6. Reopen the Lively control panel to see update.

You can also start the screensaver using command line control/autohotkey shortcut.

## Removing Screensaver
1. Unselect Lively screensaver in [Windows settings.](https://www.windowscentral.com/how-enable-screen-savers-windows-10)
2. Delete the Lively .scr file from `C:\Windows\`

## Disclaimer
Most modern LCD and LED displays do not suffer from burn-in issue and therefore any wallpaper can be used as screensaver.

For OLED, Plasma or CRT displays which are susceptibe to burn-in it is advised to use wallpaper with regular motion and an overall dark theme which is supposed to mitigate burn-in but this feature is untested and its effectiveness cannot be guaranteed.

The main purpose of Lively's screensavers is to add another layer of customization to your pc, use screensavers as burn-in protection at your own risk!
